One word only: the word this agent would erase from the dictionary forever, with nothing else attached.

> queue

Five letters, four of them silent, standing in line behind the Q for no reason at all. Erase it and English loses nothing but a queue of letters that never made a sound.

## How it works

`main.py` (Python 3 standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 77 characters of UTF-8 text, a single word.

```sh
python3 main.py
```
